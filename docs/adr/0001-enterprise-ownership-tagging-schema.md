# 1. 企业所有制分类与标签树数据模型架构

Date: 2026-08-14

## Status

Accepted

## Context

企标管理系统需要为企业建立权威的所有制分类体系（包含 4 大类：国有企业、民营企业、港澳台投资企业、外商投资企业，以及 19+ 个精细化小类标签，如央企、省属国企、国有控股企业等）。

由于部分企业同时兼具行政管辖层级（如省属国企）与股权控制类型（如国有控股企业）的双重属性，需要支持主大类识别与小类多标签叠加。此外，每一个小类均有国家国资委及法律法规给出的官方权威定义。

在模型设计上，有单表 JSON 字段存储与规范化关系表（M2M）两种主要选择。

## Decision

我们决定采用**规范化关系表设计（独立分类/标签节点模型 + 多对多关系绑定）**：

1. **`CompanyCategory` 模型**：
   - 存储大类和小类节点的树状结构（包含 `parent` 外键）。
   - 字段包括：`code`（分类编码）、`name`（名称）、`category_type`（分类类型：大类/小类）、`definition`（官方权威定义）、`sort_order`（排序）。
2. **`Company` 与 `CompanyCategory` 多对多关联**：
   - 建立 `Company` 到 `CompanyCategory` 的 M2M 关联，允许企业绑定一个主大类和多个小类标签。
   - 在关系表上建立联合索引，提升组合筛选性能。

## Consequences

### Positive
- **结构清晰严格**：符合数据库三范式，避免了 JSON 字段可能带来的脏数据。
- **动态文案与定义支持**：官方定义可以直接存储在数据库中，前端可在打标选择框旁提供 Tooltip 浮窗提示。
- **高效率统计**：便于直接进行 SQL 级别的分组统计（如“统计各省属国企数量”）。

### Negative / Trade-offs
- 需要增加新的数据库表和 Django Migration 文件。
