# 3. 区域社会组织多角色标准资产导出引擎设计

Date: 2026-09-28

## Status

Accepted

## Context

企标管理系统（EMIS）用户在进行区域（如“福建省”）行业协会及社会团体标准化摸底时，需要导出该地区所有协会的名单以及标准资产。
传统导出模式存在以下局限：
1. **统计口径单一**：旧版导出仅统计协会作为申报/主发布主体的团体标准（如福建省标准化服务行业协会仅有 95 项），忽略了协会作为参编单位起草的团体标准（14 项）以及参与起草的国家标准（2 项），导致无法获取机构 111 项的全景标准资产。
2. **缺乏多角色自由组合**：不同业务场景诉求差异显著——主管部门关注“国家标准起草单位”，而团标研究机构关注“主发布团体标准”或“参编团体标准”。系统需要支持用户按需单选或多选参与身份。
3. **摸底排查与有效资产双重诉求**：用户既需要导出“有标准资产的协会名单”，在特定行政监管普查时也需要包含“无标准资产的协会底册”。

## Decision

我们决定在系统【高级导出】（Advanced Export）引擎中深度整合**社会组织多角色标准资产导出能力**：

1. **统一入口融合**：
   - 复用现有【高级导出】弹窗中的层级地域筛选（省/市/区县）与民政登记主管机关筛选。
   - 在导出内容中提供【社会组织及标准资产目录】，并动态级联展开多角色复选框：
     - `publisher_group`：主发布单位（团体标准）
     - `drafter_group`：参编单位（团体标准）
     - `drafter_national`：参与起草国家标准
     - `drafter_industry_local`：参与起草行业/地方标准
2. **零资产协会可控输出**：
   - 默认仅输出在所选角色下拥有至少 1 项标准的协会及其实际明细。
   - 增加 `include_zero_standard_associations` 复选框，勾选后将该地区所有在册社会组织全部纳入名单，满足全量摸底普查需求。
3. **双 Sheet 报表架构**：
   - **Sheet 1【社会组织及标准资产概览】**：展示协会基本信息（名称、统一社会信用代码、民政官方统一法定代表人、申报负责人、所属地、登记主管机关）及各参与角色下的分项统计与合计数。
   - **Sheet 2【社会组织标准明细全清单】**：展平输出每项标准明细，包含标准编号、中文名称、【标准类别】（国标/团标等）、【参与角色】（主发布/参编）、署名排名、状态及日期，支持 Excel 自带数据筛选与透视。

## Consequences

### Positive
- **全景覆盖**：彻底打通协会主发布与参编起草（国标/行标/地标/团标）的全链路数据穿透，完整导出 111 项标准全集。
- **业务灵活**：支持用户随意组合角色（单选/多选），一套引擎满足多样化统计要求。
- **与界面卡片数据严格对齐**：导出表格中的法定代表人与标准统计数量与前端社会团体画像卡片实现 100% 对齐。

### Negative / Trade-offs
- 跨多库联合检索（`compare_conp.ent_std_maker` + `STSC_standard_database.std_tb_detail` + `unit_dict` / `std_unit_relation`）数据量较大，需要后端针对性进行批量分块（Chunking）优化与内存索引映射以保证导出性能。
