## 二、 核心修改点与技术方案

### 1. 引用记录页面 Infinite Loading 骨架屏 Bug 修复
*   **问题现象**：首次切换到“引用记录”页面时，列表数据无限加载中（转圈圈），无法正常渲染。
*   **修复方案**：
    *   在 [Analysis/index.tsx](file:///e:/企标管理系统_企标记录/emis/frontend/src/pages/Client/Analysis/index.tsx) 与 [ReverseTracer.tsx](file:///e:/企标管理系统_企标记录/emis/frontend/src/pages/Client/Analysis/components/ReverseTracer.tsx) 中重写了加载态控制逻辑。
    *   将 API 请求包裹在原生的 `try...catch...finally` 结构中，确保在 `finally` 块中**强制调用 `setLoading(false)`**。即使遇到网络波动、未登录授权（401）或返回数据为空等异常，也会立即释放 loading 骨架屏，防止界面卡死。

### 2. 左右卡片高度对齐 (等高布局)
*   **问题现象**：左侧“企标反向溯源”与右侧“排行榜”卡片高度受内部表格行数影响，导致底部高低不一，视觉体验差。
*   **修复方案**：
    *   在父级容器 [Analysis/index.tsx](file:///e:/企标管理系统_企标记录/emis/frontend/src/pages/Client/Analysis/index.tsx) 中，给包裹两个卡片的 Antd `<Row>` 栅格组件设置了 **`align="stretch"`** 属性。
    *   修改子组件 [ReverseTracer.tsx](file:///e:/企标管理系统_企标记录/emis/frontend/src/pages/Client/Analysis/components/ReverseTracer.tsx) 和 [NationalLeaderboard.tsx](file:///e:/企标管理系统_企标记录/emis/frontend/src/pages/Client/Analysis/components/NationalLeaderboard.tsx) 中最外层的 `<Card>` 样式：
        *   添加 `style={{ height: '100%', display: 'flex', flexDirection: 'column' }}`。
        *   配置 `bodyStyle={{ flex: 1, display: 'flex', flexDirection: 'column' }}`。
    *   使内部卡片容器随外部 Flex 轴自适应纵向拉伸填满，使两边底线永远在同一水平线上。

### 3. 企标反向溯源表格 UI 与功能修复
*   **起草单位长文本截断**：
    *   在 `columns` 起草单位的配置项中增加 `ellipsis: true`，使其超出宽度后自动显示为 `...`。
    *   在 `render` 中使用 **`Antd <Tooltip>`** 包裹渲染内容，让用户在鼠标悬浮时可以查看企业全称，解决了撑破表格列宽的问题。
*   **操作列图标精简**：
    *   将原有的 `<Button>详情制定</Button>` 纯文字按钮替换为无背景的极简图标按钮：`<Button type="text" icon={<EyeOutlined />} />`。
    *   外层包裹 `<Tooltip title="查看详情">`，使表格界面看起来更加精致现代。
*   **搜索过滤功能失效修复**：
    *   原先的 Input 和 Button 没有联动，且后端 `keyword` 传参未生效。
    *   重构为 Antd 的复合搜索组件 `<Input.Search placeholder="..." onSearch={handleSearch} enterButton />`。
    *   搜索触发时将关键字更新至 `searchParams` 状态中，驱动 `useEffect` 重新加载接口列表。

### 4. 企标在线预览与被引用标准 Excel 导出
*   **在线预览 (Modal + iframe)**：
    *   在标准列表操作列新增“预览”（👁️）按钮。
    *   点击后唤起时效性带 JWT 鉴权 Token 的预览弹窗，使用原生 `iframe` 直读 PDF，关闭时即时销毁 iframe 释放内存。
*   **子折叠表与 Excel 导出 API**：
    *   在“搜索企标”表格中开启 `expandable`，折叠展开可以清晰查阅引用标准列表。
    *   后端使用 `openpyxl` 内存构建 `.xlsx`，并通过 `prefetch_related` 将关联的引用标准以极优性能一并导出，前端采用 Blob 文件流拦截保存，规避浏览器直接打开 URL 产生的 401 权限问题。

### 5. 自定义打包弹窗优化
*   **省市多选限制**：
    *   将 `TreeSelect` 改为体验更为友好的分组 `Select` 控件（省份 OptGroup 级联）。
    *   最多限制选择 10 个地域，并在表单校验失败时显示醒目的红色必填错误语。
*   **卡片式单选 Radio**：
    *   在打包模式选择中，重构为了大卡片式的单选按键。被选中卡片会有精致的呼吸感阴影与淡蓝边框，未选中为浅灰，营造现代 SaaS 交互感。

## 三、 部署核对建议

完成推送后，请在 Linux 服务器终端按以下顺序升级生效：

1.  **拉取最新代码并构建前端**：
    ```bash
    cd ~/emis_v2/xiangmu/emis/frontend
    git pull
    npm run build
    ```
2.  **拉取后端代码并激活环境**：
    ```bash
    cd ~/emis_v2/xiangmu/emis/backend
    git pull
    conda activate qb_system
    # 可选：本次未调整数据库表结构，可直接进入下一步
    # python manage.py migrate
    ```
3.  **重启托管的 Gunicorn & Celery 进程**：
    ```bash
    pm2 restart emis-backend emis-celery
    ```
