# EMIS 异步解耦批量导入企标与引用 - 升级与使用说明文档

本文档详细记录了新开发的 **“异步解耦批量导入企标与引用（混合表）”** 功能的架构设计建议、代码修改清单以及用户使用说明。此文档可用于跨对话、跨版本迭代时快速对齐业务与技术细节。

---

## 1. 架构与设计决策

### 业务场景：什么是“异步解耦导入”？
为了提升大批量标准（成千上万行）导入时的稳定性，我们开发了**异步解耦批量导入**机制。
- **避免网关超时（504 Gateway Timeout）：** 解析 Excel 包含查重、地标级联对齐、外键创建等多步操作，同步解析大文件会长时间阻塞 HTTP 连接。通过将文件写入临时盘，立即返回 `task_id`，利用 Celery 在后台异步解析，前端通过轮询（Polling）机制获取进度，极大提升了可靠性。
- **行级数据库事务（Row-level Atomicity）：** 后台任务中，对于每一行数据，均使用 `transaction.atomic()` 嵌套。保证本行关联的“企业建档”、“标准主表建立”、“引用明细关系建立”三者作为原子操作入库。如果某行因为数据残缺、保存失败，该事务只回滚当前行，并捕获异常，记录详细原因，不影响其他合法行的高速入库。

## 2. 代码修改明细 (Code Modification Manifest)

本次功能升级共修改和新增了以下 **5 个文件**：

### 2.1 后端修改 (Django / Celery)

#### 1. 新增混合模板生成服务 —— [services.py](file:///e:/企标管理系统_企标记录/emis/backend/standards/services.py)
*   **新增函数 `generate_mixed_import_template_v2()`：** 
    - 动态生成 Excel，表头为：`['企标编号*', '企标名称*', '起草单位*', '统一社会信用代码*', '引用的国标/行标编号*', '最新标准号']`。

#### 2. 新增 Celery 异步任务定义 —— [tasks.py](file:///e:/企标管理系统_企标记录/emis/backend/standards/tasks.py)
*   **新增任务 `import_standards_and_references_task(self, file_path, task_token)`：**
    - **状态与进度推送：** 在缓存中初始化任务记录，每解析 5% 自动刷新进度，并更新当前累计的成功/失败行数与错误原因列表。
    - **表头容错匹配：** 使用正则和别名集合，智能容错匹配诸如“起草单位/企业名称”、“被引用标准号”等不同版本的 Excel 属性名。
    - **严格行级事务：** 对每一行，自动在 `Company` 查重建档、在 `Standard` 查重入库、匹配被引国标并建立 `NormativeReference`，发生异常时安全捕获，写入行错误日志：`{"row": 行号, "reason": "错误原因"}`。
    - **PDF 后置扫盘：** 导入结束后，自动唤起 `scan_and_align_pdf_assets` 以对齐物理共享磁盘阵列上的 PDF 资源。
    - **状态持久化：** 执行完毕后，缓存标记 `status = 'done'` 并自动清理临时 Excel 文件。

#### 3. 新增 API 控制器 —— [admin_views.py](file:///e:/企标管理系统_企标记录/emis/backend/standards/views/admin_views.py)
*   `StandardMixedImportView` (POST)：接收上传的文件，生成随机 UUID Token 并将文件写入磁盘 `media/temp_uploads/` 目录下，随后火速调用 `import_standards_and_references_task.delay(file_path, task_token)` 移交 Celery 处理。
*   `StandardMixedImportStatusView` (GET)：以 `task_id` 查询缓存，反馈任务当前状态（`pending/running/done/failed`）和进度详情。
*   `StandardMixedImportTemplateView` (GET)：获取混合模板字节流并输出下载。

#### 4. 路由注册 —— [admin_urls.py](file:///e:/企标管理系统_企标记录/emis/backend/standards/urls/admin_urls.py)
注册端点：
- `POST /api/admin/standards/import-mixed/` (数据上传端点)
- `GET /api/admin/standards/import-mixed/status/` (进度查询端点)
- `GET /api/admin/standards/import-mixed/template/` (混合模板下载端点)

## 3. 使用手册 (User Manual)

### 步骤一：下载模板
1. 进入管理后台的「企业标准管理」模块。
2. 点击右上角新增的灰色 `ghost` 按钮 **「一键导入企标与引用」**。
3. 点击 **「下载混合表导入模板 (.xlsx)」**，下载标准的表头文件。

### 步骤二：准备数据并录入
混合模板中各列要求如下：
- **`企标编号*` / `企标名称*`（必填）：** 要入库的企业标准基本信息。
- **`起草单位*` / `统一社会信用代码*`（必填）：** 该标准所关联的起草单位基本数据，后台将据此查重并自动进行地图落位。
- **`引用的国标/行标编号*`（必填）：** 具体的引用标准号。如一根企标有 10 个引用，需要写成 10 行，第一部分（企标基本信息）保持相同。
- **`最新标准号`（选填）：** 若有关联最新标准可在此备注。

### 步骤三：上传并观察状态
1. 选中或拖拽填好的混合表上传。
2. 页面进入**“后台异步拆分与事务入库执行中...”**状态。
3. 您可以直观看到进度条以百分比形式上涨，以及成功条数和异常条数的计数。**（注意：此时可以关闭弹窗，任务仍会在 Celery 中静默执行完毕。）**
4. 任务结束后，如果有错误行，可参考下方列表的行号和原因进行修正，对于正确的数据则已安全存入数据库中。
