# 🎨 EMIS 企标检索面板 - 样式精进化设计方案

本方案旨在将现有的双行、多图标、高纵向占用的“查询企业”检索面板，彻底重构为用户期望的**单行流式紧凑布局（Single-row Compact Layout）**。新设计将极大提升屏占比，呈现极简、高端、扁平化的现代企业级 CRM 质感。

---

## 📐 新旧样式深度对比与重构要点

| 维度 | 当前样式 (图一) | 精进后样式 (图二) | 重构动作 |
| :--- | :--- | :--- | :--- |
| **纵向高度** | 较宽，双行排布，带有分割线，高度约为 240px | **极简单行排布**，无分割线，高度约为 90px | **压缩 60% 纵向空间**，使企业列表卡片能直接置顶呈现。 |
| **标题与图标** | 带有“关键词检索 (罗盘图标)”和“三级行政区划 (地球图标)”子标题 | 仅保留最上方一个弱化的 **“检索条件”** 分类小标题，无图标，极简白描 | **彻底移除子标题、分割线和图标**，让视觉重心完全聚焦于输入框本身。 |
| **关键词输入框** | 独占一整行，标签为“企业关键词” | **与下拉框在同一行水平排列**，占 25% 宽度，提示词精简为 `企业名称 / 信用代码 / 模糊...` | 移除 Form Item 的 Label，改为行内占位符，实现左右对齐。 |
| **行政区划下拉** | 另起一行，标签为“选择省份/城市/区县” | **紧随关键词输入框之后，水平等宽一字排开** | 移除外置 Label，默认提示占位符简化为 `省份`、`城市`、`区/县`。 |
| **操作按钮组** | 偏大，蓝色调，文字为“清空条件”和“立即检索” | **紧随在区县下拉框后**，文字精简为 **“清空”** 和 **“检索”** | 检索按钮采用**高级深藏青色系**（如 `#0b1d33`），清空按钮为纯白扁平质感。 |

## 🧩 关键布局 Grid 栅格规划 (24 栅格分配)

为了在任意屏幕分辨率下完美单行自适应，我们将采用 Antd 的 `Row` 和 `Col` 栅格进行精准比例划分：

```
+---------------------------------------------------------------------------------------------------------+
|                                              检索条件                                                   |
|  +------------------------+  +----------+  +----------+  +----------+  +------------+  +------------+  |
|  | 企业名称 / 信用代码... |  |   省份   |  |   城市   |  |  区/县   |  |   C 清空   |  |   Q 检索   |  |
|  +------------------------+  +----------+  +----------+  +----------+  +------------+  +------------+  |
|         Col: 7                 Col: 4        Col: 4        Col: 4          Col: 2.5        Col: 2.5     |
+---------------------------------------------------------------------------------------------------------+
```

*   **企业关键词** (`Col span={7}`)：最左侧，稍宽，以便完整显示输入字符。
*   **省份选择** (`Col span={4}`)：中间。
*   **城市选择** (`Col span={4}`)：中间。
*   **区/县选择** (`Col span={4}`)：中间。
*   **清空按钮** (`Col span={2}`) 或 `span={2.5}`：右侧，扁平灰色/无底色边框。
*   **检索按钮** (`Col span={3}`) 或 `span={2.5}`：最右侧，**深藏青色底色** (`background: '#0b1d33'`)，高亮对比。

## 🎨 视觉细节参数控制

1.  **卡片容器 (Card)**：
    *   移除大阴影，改为超精细浅边框：`border: '1px solid #e8e8e8'`
    *   内边距收缩：`bodyStyle={{ padding: '16px 20px' }}`
2.  **输入与选择控件 (Input & Select)**：
    *   高度统一设定为中等标准高：`size="middle"` (高度 32px) 或统一 `size="large"`（高度 40px，更加沉浸大气）。**建议采用 38px/40px 黄金高度**，极具质感。
    *   圆角微调为大厂风范：`borderRadius: 6` 或 `borderRadius: 4`
3.  **高级深藏青检索按钮 (Search Button)**：
    *   背景色：`#0b1d33` (Midnight Navy Blue)
    *   文字颜色：`#ffffff`
    *   悬停效果 (Hover)：悬停时为深蓝色，配合极佳的微交互反馈。
