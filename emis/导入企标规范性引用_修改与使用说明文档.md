# EMIS 企标规范性引用目录导入 - 升级与使用说明文档

本文档详细记录了针对“企业标准管理”模块中新增的 **“导入规范性引用”** 功能的架构设计建议、代码修改清单以及用户使用说明。此文档可用于跨对话、跨版本迭代时快速对齐业务与技术细节。

---

## 1. 架构设计与业务逻辑总结

### 业务决策：为何保持“分开两个入口”？
在系统设计阶段，我们评估了**“企标主表与引用明细合一导入”**与**“主表与引用分步导入”**的利弊。最终推荐采用 **分开两个独立入口，在引用导入时进行存在性严格校验** 的方式：
1. **防止数据高度冗余与一致性问题：** 企标主表字段较多（包括企业名称、信用代码、法人、地址等），而一根企标可能对应数十条引用记录（一对多）。如果合在单一 Sheet 中导入，用户需要在每一行重复录入企标的主体信息，这极易导致同一企标在不同行填写的属性不一致，造成严重的脏数据；若采用双 Sheet 导入，对于非技术运营人员编辑公式的门槛太高。
2. **切合实际数据采集时序：** 企标主表元数据一般在录入标准库时即创建（或者自动扫盘 PDF 建档）。而具体的规范性引用链目录多是经过后期 OCR 识别或解析提取出列表后，才进行二次绑定的。
3. **静默建档与关联提示：** 通过拆分，我们保持了轻量级、职责单一的模板。导入引用记录时，后端会校验企标号在系统库中是否存在，若不存在则报出明确的报错行号提示，防止出现无法追溯源头的孤立引用。

## 2. 代码修改明细 (Code Modification Manifest)

本次功能升级共修改和新增了以下 **4 个文件**：

### 2.1 后端修改 (Django / DRF)

#### 1. 新增与完善底层服务函数 —— [services.py](file:///e:/企标管理系统_企标记录/emis/backend/standards/services.py)
*   **修复遗漏样式引入：** 引入了 `from openpyxl.styles import Font, PatternFill, Alignment`，修复并规范了 Excel 模板的表头底色、字体样式。
*   **新增函数 `generate_reference_import_template_v2()`：** 动态生成包含标准必要表头的 Excel 模板：`['企标编号*', '引用的国标/行标编号*', '被引用标准名称', '最新标准号']`。
*   **新增函数 `import_references_from_excel_v2(file_obj)`：** 
    - 对上传的 Excel 数据行执行解析。
    - **N+1 性能优化：** 取出全部相关的企标，使用 `in` 操作符预先缓存，消除单行循环查询数据库导致的阻塞风险。
    - **行级事务与校验：** 使用 `transaction.atomic()` 嵌套。校验 `企标编号*` 及 `引用的国标/行标编号*` 是否为空，并**强校验企标是否已存在于数据库**；如有错误收集其行号与原因并跳过，对通过校验的数据行通过 `get_or_create` 进行入库，保障导入安全性。
    - **联动计数与状态：** 导入成功后，自动将主企标的 `is_parsed` 解析状态变更为 `references_parsed`（已完成规范性引用解析），并对被引用的国/行标 `citation_count` 自动执行 `+1` 被引计数。

#### 2. 新增 API 路由端点 —— [admin_urls.py](file:///e:/企标管理系统_企标记录/emis/backend/standards/urls/admin_urls.py)
注册了两个管理后台路由：
- `POST /api/admin/standards/import-references/`（规范性引用批量导入数据接口）
- `GET /api/admin/standards/import-references/template/`（模板 Excel 文件流下载接口）

#### 3. 新增 API 控制器类 —— [admin_views.py](file:///e:/企标管理系统_企标记录/emis/backend/standards/views/admin_views.py)
- `StandardReferenceImportView`：调用服务解析 Excel 文件，并以 HTTP 200 返回包含 `{ success_count, errors: [] }` 的 JSON。
- `StandardReferenceImportTemplateView`：读取动态字节流并返回 `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` 类型的附件响应，规避乱码风险。

### 2.2 前端修改 (React + Ant Design)

#### 1. 新增导入弹窗组件 —— [ImportReferencesModal.tsx](file:///e:/企标管理系统_企标记录/emis/frontend/src/pages/Admin/Standards/components/ImportReferencesModal.tsx)
- **模板下载机制：** 使用 `apiClient` 获取 Blob 文件流，自动创建隐藏 `<a>` 标签触发浏览器下载，防止由于 Cookie/JWT 携带引发跨域下载拦截。
- **拖拽上传机制：** 使用 `<Upload.Dragger>` 实现流畅的文件上传回传交互。
- **容错反馈 UI（亮点）：** 
  - 如果数据中存在异常行，模版将弹窗内高亮呈现 `<Alert type="error" />` 错误通告；
  - 并在模版下层渲染一个精美的 `<Table>`，表格列为 **“Excel 行号” (高亮第 X 行) 以及 “冲突或格式错误原因说明”**，帮助管理员立刻定位到文件哪一行填错了。

#### 2. 主页面注入与状态管理 —— [index.tsx](file:///e:/企标管理系统_企标记录/emis/frontend/src/pages/Admin/Standards/index.tsx)
- 在右上角操作组中，在“一键导入企标”左侧嵌入了极简轻量级 `ghost` 风格的 **“导入规范性引用”** 按钮。
- 管理 `importRefVisible` 状态以唤醒和销毁新模态弹窗，成功导入后自动调用 `standardQuery.refetch()` 刷新父表的状态展示。

## 3. 管理员使用指南 (User Manual)

系统管理员可以通过以下步骤为企标批量补充规范性引用链明细：

### 第一步：下载标准模板
1. 登录 EMIS 管理后台，进入「企业标准管理」页面。
2. 点击右上角操作栏中的 **「导入规范性引用」** 按钮。
3. 在弹出的对话框中，点击 **「下载导入模板 (.xlsx)」**，下载官方的标准数据填写格式表。

### 第二步：编辑数据
下载的 Excel 模板包含四列：
- **`企标编号*`（必填）：** 企标的原始编号，如 `Q/XMBL 001-2024`。**注意：** 此编号必须在系统中已存在（已在一键导入企标中录入）。
- **`引用的国标/行标编号*`（必填）：** 该企标正文中规范性引用文件里提及的国/行/地/团标编号，如 `GB/T 19001-2016`。
- **`被引用标准名称`（选填）：** 备注引用的标准名。
- **`最新标准号`（选填）：** 若有替代或最新标准，可在此填写以展示热度替换链。

### 第三步：上传与错误定位
1. 将填写完成的 `.xlsx` 文件拖入或点击上传到弹窗内的拖拽区。
2. 系统自动解析并校验：
   - **导入成功：** 界面将显示绿色 `Alert` 提示成功导入的条数。
   - **导入包含异常：** 界面将显示红色 `Alert` 总结校验失败条数，同时弹窗下方的表格会列出每一行的错误，如：
     - *“第 3 行：企标编号 'Q/NOTFOUND-2026' 在系统企标库中未找到，请确保已一键导入该企标主表”*
     - *“第 5 行：必填列 '引用的国标/行标编号*' 为空”*
3. 管理员无需重新做表，只需对照行号修改 Excel，将有问题的行数更正或过滤，再次上传即可，已导入的无误行不会重复创建。
