# 📋 “企标反向归属溯源”系统升级实施计划

为达成您提出的前台页面及文字升级、引用解析工具收归后台，以及核心新增的**“规范性引用解析后反向追溯企标所属企业”**增值服务体系，我们精心设计了如下的重述理解、系统流转流程图与实施计划。

---

## 🎯 一、 需求深度重述与理解

### 1. 基础 UI 及翻页参数调整 (Point 1)
*   **菜单命名更改**：将前台左侧栏菜单名称 **“搜企搜标”** 变更为 **“查询企业”**。
*   **默认显示数调整**：将“查询企业”（原搜企搜标）列表的默认每页加载数量由原本的 `10` 个调整为 **`9`** 个（包含前端列表网格、分页组件条件限制、以及后端 API 分页器 PageSize 的同步修改）。

### 2. 引用统计重命名及解析工具“收归后台” (Point 2 - Part A)
*   **菜单重命名**：将前台左侧栏的 **“引用统计”** 修改为 **“引用记录”**。
*   **解析工具收归后台**：将前台“引用记录”中原本由普通会员/游客可见的 **“引用解析工具”**（Excel 上传解析卡片及规则卡片）彻底移除，安全转移并重新生成在后台管理系统的独立菜单 **“引用记录管理”** 页面中，仅限管理员操作。

### 3. 前台新增“企标反向归属溯源画像”核心功能 (Point 2 - Part B)
*   **业务痛点**：当我们在公众号、视频号等平台发布了标准解析或数据图表后，会有很多潜在企业客户主动前来联系。我们需要根据他们提供的“企业标准号”或“标准名称”，第一时间**反向查询并核实该标准属于哪家企业**、**信用代码是多少**、**是否已经在系统中完成了解析打标**，从而为其提供最专业、最迅速的高匹配度咨询服务。
*   **前台模块设计**：在“引用记录”页面左半侧，新增一个独立、极具视觉冲击力的 **“企业标准反向溯源定位系统”** 卡片：
    *   **模糊检索**：输入企标号（如 `Q/XMBL`）或标准名称。
    *   **解析标记打标**：直观展示该企标是否已被引用解析打标（`is_parsed` 为 `True` 显示绿色高亮标签，否则显示灰色未解析标签）。
    *   **企业画像反查**：一键联表反查出该企标所归属的**企业名称**、**社会统一信用代码**、**法定代表人**、**所处地区（省/市/区）**，并提供高亮视觉呈现。
    *   **客服服务通道**：一键生成“一键咨询 / 专属服务画像生成”按钮，方便运营人员随时应对企业质询。
